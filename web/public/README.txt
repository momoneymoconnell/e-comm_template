Static files served from the site root.

Put a favicon, a logo, or the verification files that payment providers and
search consoles ask you to host at a fixed path here.

robots.txt used to live in this directory and is now generated by
src/app/robots.ts, so that it can be driven by an environment variable rather
than an edit-and-rebuild. That emptied the directory, which broke the Docker
build: COPY cannot take a directory that does not exist, and git does not track
empty ones. This file keeps it present.
