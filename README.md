# e-comm template

A deployable full-stack e-commerce skeleton: Python microservices behind a
gateway, Postgres for transactions, dbt + DuckDB for analytics, and a Next.js
storefront with an admin console. The product catalogue is intentionally empty —
this is the machinery, ready for a business to be dropped into it.

Setup and architecture documentation lands as the stack is built. Start with:

```bash
make setup && make up
```
